# Week 5 Assignment: Password Generator & Your Own Module

## Files

- **password_generator.py:** Generates random passwords using Python's random and string modules.
- **helpers.py:** Contains functions for calculating tables needed and creating welcome messages.
- **main.py:** Imports the helpers module and uses its functions.
